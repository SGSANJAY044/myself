# myself

My personal site. Blog + side projects. Plain Jekyll, hosted on GitHub Pages.

## Writing a post

Add a file to `_posts/` named `YYYY-MM-DD-some-slug.md`:

```md
---
title: What I learned killing my first project
---

Write here.
```

Push. It shows up in a minute or two.

## Adding a project

Add an entry to the top of `_data/projects.yml`. Fields are explained at the top of that file.

## Hosting

Repo Settings → Pages → Source: "Deploy from a branch" → `main` / `(root)`.
